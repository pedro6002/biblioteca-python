# Sistema de gerenciamento de biblioteca

Sistema para gerenciamento de livros e usuários em uma biblioteca

---

## Sobre
Sistema criado em Python com persistência de dados em SQLite para gestão usuários, livros e empréstimos em uma biblioteca fictícia.
É possível cadastrar usuários e livros, visualizar usuários cadastrados, livros cadastrados e situações de empréstimo.

## Funcionalidades
- Cadastro e listagem de livros
- Cadastro e listagem de usuários
- Controle de empréstimos com devoluções e data de entrega

## Tecnologias
- Python
- SQLite
- Biblioteca padrao `datetime`

## Como executar

### Pré-requisitos
- Git instalado
- Python 3.10+

### Passo a passo

1. Clone o repositório:
```bash
git clone [https://github.com/pedro6002/biblioteca-python.git](https://github.com/pedro6002/biblioteca-python.git)
cd biblioteca-python
```
2. Execute o sistema:
python main.py
